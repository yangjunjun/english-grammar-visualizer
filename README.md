# 句间 · Sentence Lab

英语句子结构的交互学习原型。使用原生 HTML、CSS 和 JavaScript，无依赖、无构建步骤。

## 打开

直接用浏览器打开 `index.html`。也可以在项目目录运行 `python3 -m http.server 5173`，再访问 `http://localhost:5173`。

## 当前内容

- 左侧树形目录：五种基本句型、主语从句、原因状语从句，共 7 个语法点。
- 骨骼与完整句切换，逐层添加修饰语。
- 点击成分查看角色、构成类型和解释。
- 点击带加号的短语或从句，以同色箭头连接下方的独立分析区；连线随布局调整。
- 每个内部分析区复用主句交互，独立切换骨骼与完整结构、逐层搭建、点击成分查看本层解释，并支持继续展开和收起。已经是最简骨骼的结构会显示说明。
- 小屏幕可折叠菜单，支持键盘操作与减少动画偏好。

本版使用人工编写的教学示例，不包含任意句子的自动分析功能。五种基本句型采用传统教学框架，不代表英语所有结构都能简单归为五类。

## 调整样式与示例

`styles.css` 的 `:root` 集中定义成分颜色、构成相近色、字体、字号、间距基数、边框、圆角、内容宽度和导航宽度。`app.js` 的 `lessons` 定义目录及例句的分层内容；`children` 定义可展开的内部结构。
